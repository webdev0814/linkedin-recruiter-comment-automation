# Public Repo Scope

This repository intentionally includes only the reusable, public-safe parts of the LinkedIn comment workflow.

Included:

- engagement rules and safety constraints
- daily workflow guidance
- public-ready templates
- repo documentation

Excluded:

- personal resumes or profile drafts
- personal contact details
- account-specific exports or browser artifacts
- recruiter lead lists tied to an individual
- generated daily queues for a specific person
- third-party page captures and scraped assets
